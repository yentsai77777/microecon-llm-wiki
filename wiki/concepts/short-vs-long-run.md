# 跨單元概念：短期 vs. 長期決策對照
- **關聯單元**：Ch.7 (p.27–32)、Ch.8 (p.11–18)、Ch.10 (p.23–29)

| 比較維度 | 短期 (Short Run) | 長期 (Long Run) |
| :--- | :--- | :--- |
| **固定要素** | 廠房規模固定，存在固定成本 $F$ | 所有要素皆可調整，無固定成本 |
| **成本曲線** | 短期平均成本 $SAC$ | 長期平均成本 $LAC$（所有 $SAC$ 的下包絡線） |
| **繼續營業條件** | $p > AVC$（只要補貼得了固定成本就開門） | $p > AC$（虧錢就直接退出市場） |
| **市場進出與利潤** | 廠商數量固定，可能賺錢也可能虧錢 | 自由進出市場，長期均衡「經濟利潤 = 0」 |
